# Version 1.1.0

Initial public submission of the skills-only nOva UX Intelligence plugin.

- Frozen Reasoning Kernel v1.0 with challenge, evidence, preservation, uncertainty and conflict handling.
- Chat critique and hands-on code implementation modes.
- Phone and iPad adaptation, accessibility, localization/RTL, failure-state and runtime verification guidance.
- Liquid Glass as a preferred selectable direction rather than a default.
- Regression coverage for T1-T13, adversarial scenarios and FM-01 through FM-18.
- No connector, external authentication or developer-controlled data collection.
