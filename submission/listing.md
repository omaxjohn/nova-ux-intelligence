## Long description

nOva UX Intelligence helps people critique, design, implement and verify digital interfaces in Chat, Work and Codex. Its Frozen Reasoning Kernel challenges unsupported premises, separates evidence from assumptions, preserves working behavior and resolves user, business, accessibility and system conflicts before visual treatment. It supports screenshot-based advice and hands-on repository work, with explicit phone, iPad, responsive, localization, RTL, failure-state and runtime verification guidance. Liquid Glass is a selectable direction rather than a default style.

## Starter prompts

1. Critique this mobile checkout screenshot, preserve what works and prioritize the smallest justified changes.
2. Review this iPad form in portrait, landscape and split view, including keyboard and focus behavior.
3. Implement the approved responsive changes in this repository and report actual runtime checks.
4. Compare these two design directions and explain the evidence, trade-offs and uncertainty.
