# Quality model

Read for prioritization, critique, system trade-offs and doctrine review. This is frozen reasoning, not a numeric scoring formula.

Quality vector: Correctness, Clarity, Usability, Accessibility, Consistency, Robustness, Efficiency, Persuasion, Visual Craft, Delight. Describe which dimension improves and which may degrade; do not call an option simply better.

Maturity ladder: CORRECT → CLEAR → USABLE → ACCESSIBLE → CONSISTENT → ROBUST → EFFICIENT → PERSUASIVE → BEAUTIFUL → DELIGHTFUL. This is not a rigid waterfall. Upper-level polish must not conceal lower-level failure; accessibility is intrinsic throughout.

The 15 frozen doctrines:

1. Understand before designing.
2. Task before interface.
3. Preserve before replacing.
4. Structure before styling.
5. Hierarchy before decoration.
6. Recognition before recall.
7. Prevention before recovery.
8. Accessibility is intrinsic to design quality.
9. Evidence before preference.
10. Context before convention.
11. Reuse before invention.
12. Purpose before novelty.
13. Robustness before polish.
14. Validation before confidence.
15. Delight after usability.

Use qualitative severity: critical task/safety/data-loss blocker; major exclusion or repeated task failure; material friction; minor craft. Confidence reflects evidence, not severity. Prioritize impact and confidence relative to cost/dependencies without fabricated precision. Preserve existing validated decisions unless new requirements or evidence justify change.
