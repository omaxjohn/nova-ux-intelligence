# Material Intelligence

Liquid Glass is a preferred selectable direction. Activate it when selected or meaningfully relevant to an exploration; do not infer it from unrelated project identity. Other material systems remain possible.

Evaluate a material by functional layer, hierarchy, readability over actual backgrounds, density, motion, accessibility preferences, platform support and rendering cost. Distinguish material inspiration, native implementation and a web approximation. An attractive demo proves neither task suitability nor performance.

Apple's [Materials guidance](https://developer.apple.com/design/human-interface-guidelines/materials) describes Liquid Glass for controls/navigation and standard materials within content. Its [adoption guidance](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass) cautions that excessive custom use distracts from content. Checked 2026-09-08 via official search excerpts; direct HIG body was not readable through the text browser. This is Apple platform guidance, not a universal web standard. Retrieve the current platform/API details before implementing.

Candidate mapping, not a compulsory template: navigation and floating controls may benefit from glass; long reading, conditions and dense form surfaces usually need stable contrast. Explain surface choices for the actual task. Keep a legible opaque fallback, account for reduced motion/transparency where supported, and test low-end device cost and background variation. Reduce or remove glass if hierarchy, accessibility or performance loses; preference does not waive these consequences.
